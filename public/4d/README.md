# Tower office (4D)

The glossy-blob tower shown when Office quality is **4D**.

Vendored from [Bodila51/grokbot-wallpaper](https://github.com/Bodila51/grokbot-wallpaper) (`web/scene`, plus `assets/office/office.glb` and the night lightmaps). The page bundles that renderer as `/office4d.js`. Bot seats, looks and floors come from the wallpaper feed already in this app. The topic is not stored in this folder.
